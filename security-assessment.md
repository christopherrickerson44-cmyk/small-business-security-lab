# Small Business Security Assessment

## Assessment Objective

The purpose of this assessment is to identify common cybersecurity risks within a fictional small-business environment and recommend security controls to reduce those risks.

## Business Environment

The fictional organization has:

- 10 employees

- 10 desktop computers

- 1 wireless network

- 1 router/firewall

- 1 network printer

- 1 file server

## Risk Assessment

### 1. Weak Passwords

**Severity:** High

**Risk:** Weak passwords could allow an unauthorized person to gain access to employee accounts.

**Recommendation:**

- Require strong passwords

- Encourage unique passwords for every account

- Enable multi-factor authentication (MFA) where available

- Educate employees about password security

### 2. Shared User Accounts

**Severity:** High

**Risk:** Shared accounts make it difficult to determine who accessed or changed information.

**Recommendation:**

- Create individual accounts for every employee

- Apply least-privilege access

- Remove accounts when employees leave the company

### 3. Unsecured Wi-Fi

**Severity:** High

**Risk:** An improperly secured wireless network could allow unauthorized devices to connect to the business network.

**Recommendation:**

- Use WPA2 or WPA3 encryption

- Use a strong wireless password

- Change default router credentials

- Create a separate guest network

### 4. Outdated Software

**Severity:** Medium

**Risk:** Outdated software may contain known vulnerabilities that attackers can exploit.

**Recommendation:**

- Enable automatic updates when appropriate

- Establish a regular patching schedule

- Maintain an inventory of business devices and software

### 5. No Documented Backup Plan

**Severity:** High

**Risk:** Hardware failure, ransomware, or accidental deletion could result in data loss.

**Recommendation:**

- Perform regular backups

- Keep at least one backup separate from the primary system

- Test backups regularly

- Document the backup procedure

### 6. No Incident Response Plan

**Severity:** Medium

**Risk:** Employees may not know what to do if the organization experiences a cybersecurity incident.

**Recommendation:**

Create a documented incident response procedure that explains:

1. How to identify an incident

2. Who should be notified

3. How affected systems should be isolated

4. How evidence should be preserved

5. How systems should be recovered

6. How the incident should be documented

## Overall Assessment

The fictional organization has several areas that should be improved before it can be considered adequately protected against common cybersecurity threats.

The highest priorities are:

1. Strong authentication and MFA

2. Individual user accounts

3. Secure wireless networking

4. Reliable backups

5. Regular software patching

6. An incident response plan

## Conclusion

This assessment demonstrates how cybersecurity fundamentals can be applied to a realistic small-business environment.

The recommendations are designed to reduce common risks while maintaining practical and affordable security controls.

## Disclaimer

This is a fictional educational cybersecurity lab created for learning and portfolio development. No real systems were scanned, attacked, or tested.
