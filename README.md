# small-business-security-lab
## project overview
this project simulate a cybersecurity assessment for a small business network.
the goal is to identify common cybersecurity risks, evaluate the potential impact of those risks , and recommend practical security controls.
## scenario
the fictional company has:
-10 employees
10 desktop computers
1 wireless network
1 router/firewall
1 network printer
1 file server
##security risk identified 
| risk| severity | recommendation |
|----|----|----|
|weak passwords | high| enforce strong password requirements|
|shared user accounts| high| create individual user accounts|
|unsecured Wi-Fi| high | use WPA2/WPA3 security|
|outdated software| medium | establish a regular patching schedule|
|no documented backups| high| implement regular backups|
|no incident response plan | medium | create an incident response procedure|
##what i learned
through this project, i practiced applying cybersecurity concepts to a realistic, small-business environment.
i learned how to identify common security risk, evaluate their potential impact, and recommend security controls to reduce those risk.

this is a fictional educational lab created for cybersecurity learning and portfolio development.
